# Tangent 中文兼容版

**选中一段，另开一支；追问细节，继续阅读。**

为 ChatGPT 和 Claude 网页添加浮动分支对话的浏览器扩展。本项目基于 [cursed-github/tangent](https://github.com/cursed-github/tangent) 修改，重点修复中文 ChatGPT 界面下无法显示 `Open Thread` 的问题。

使用浏览器中已有的登录会话，**无需 API Key，无需构建**。本分支版本为 **1.2.2**，基于上游 1.2.1。

## 为什么需要分支对话？

用 ChatGPT 学习代码、读长解释时，常常只想追问其中一句话或一段代码。直接在主对话提问，会不断增加消息，让原本正在阅读的内容越来越远。

Tangent 让你选中不懂的内容，在旁边打开临时对话：深入问清这个细节，再回到主解释继续阅读。你也可以分别为不同问题保留多个侧线程，随时最小化和恢复。

## 功能

- **选中即追问**：选中文字或代码，点击橙色 `Open Thread`，在浮动窗口中继续讨论。
- **携带选中内容**：尝试将选区自动填入侧线程，作为追问的上下文。
- **多个侧线程**：分别讨论不同问题，支持最小化与恢复。
- **沿用已有账号**：使用 ChatGPT 或 Claude 的网页登录会话。可用模型、用量限制及订阅权益由对应平台决定。

## 本分支的兼容修改

上游 1.2.1 的 ChatGPT 按钮识别依赖英文 `Ask ChatGPT` 和旧版 CSS 类名。本分支调整了识别逻辑：

| 项目 | 支持内容 |
| --- | --- |
| 简体中文 | `向 ChatGPT 提问` |
| 繁体中文 | `向 ChatGPT 提問`、`詢問 ChatGPT` |
| 其他语言 | 保留 `Ask ChatGPT`，加入 `ChatGPT に質問`、`ChatGPT에게 질문` |
| 识别方式 | 同时检查按钮文字、`aria-label` 和 `title` |
| 网页结构适配 | 移除对旧版 `btn-secondary` 类名的依赖 |
| 动态更新 | 监听按钮插入、子节点变化和标签属性更新 |

这里的“中文兼容”指 ChatGPT 选区按钮识别；浮动窗口中的 `Open Thread` 等界面文字仍沿用上游英文。日语、韩语已加入标签匹配，尚未逐语言实测。

## 安装

1. 点击本仓库页面的 **Code → Download ZIP**，解压到准备长期保留的位置。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 如果已安装商店版 Tangent，请先停用，避免两个版本同时运行。
4. 打开右上角的 **开发者模式**。
5. 点击 **加载已解压的扩展程序**。
6. 选择包含 `manifest.json` 的文件夹，而不是 ZIP 文件或它的外层文件夹。
7. 刷新已打开的 [ChatGPT](https://chatgpt.com) 或 [Claude](https://claude.ai) 网页。

安装后请保留该文件夹，避免移动或删除。更新源码后，在扩展管理页点击扩展的重新加载按钮，再刷新聊天网页。

## 使用

1. 登录 ChatGPT 或 Claude 网页，打开一段对话。
2. 在回答中选中至少 **10 个字符**的文字或代码。
3. 点击橙色 **Open Thread** 按钮。
4. 等待浮动窗口加载，确认选中内容已填入，再继续追问。
5. 最小化窗口，继续阅读主对话；需要时再恢复侧线程。

如果自动填入失败，可以手动复制选中的内容并粘贴到侧线程。侧线程只携带选区内容，不应假定它自动拥有主对话的完整历史。

## 权限与数据处理

本扩展没有独立后端；当前源码未包含额外的统计或遥测服务。侧线程加载平台网页，输入及选中内容仍由对应平台处理，并适用平台的数据政策。

| 权限或机制 | 用途 |
| --- | --- |
| `https://chatgpt.com/*`、`https://claude.ai/*` | 在这两个站点注入选区按钮和浮动面板逻辑 |
| `clipboardWrite` | 将选中内容复制到剪贴板 |
| `declarativeNetRequest` | 沿用上游 iframe 适配规则，移除 ChatGPT 子框架响应中的 `X-Frame-Options` 和 `Content-Security-Policy` 响应头 |
| `sessionStorage` | 临时传递选中内容，让同站点侧线程读取并填入 |

## 验证状态与限制

- 已通过 JavaScript 语法检查、Manifest 和规则 JSON 解析，以及打包文件完整性检查。
- **尚未完成本版本安装后的真实端到端验证**，不保证所有语言、账号或平台页面都能正常运行。
- 扩展依赖 ChatGPT、Claude 的网页结构及 iframe 行为。平台更新可能导致按钮识别、页面嵌入或上下文填入失效。
- 侧线程使用上游的临时对话入口；实际保存行为由平台决定。刷新、关闭页面前，请自行保存重要内容。

反馈问题时，请附上浏览器版本、平台、界面语言、复现步骤及经过隐私处理的截图；请勿上传登录凭据或私人对话。

## 技术与文件

Chrome Extension Manifest V3，原生 JavaScript 与 CSS，无需安装依赖或执行构建。

```text
.
├── manifest.json   # 扩展配置与权限
├── content.js      # 选区识别、浮动线程、平台交互
├── styles.css      # 浮动窗口样式
├── rules.json      # ChatGPT iframe 响应头适配规则
├── icons/          # 扩展图标
├── 安装说明.txt     # 简明安装指南
├── CHANGELOG.md    # 本分支变更记录
└── LICENSE         # 上游 MIT 许可证
```
